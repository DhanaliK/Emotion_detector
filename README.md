# Repository for final project
Project Description
Emotion Detector is an AI-based web application that analyzes text and detects emotions using the Watson NLP library.

The application identifies the following emotions:

Anger
Disgust
Fear
Joy
Sadness
It also identifies the dominant emotion in the given text.

Technologies Used
Python
Watson NLP
Flask
Unittest
PyLint
GitHub
Project Objective
The objective of this project is to develop, test, package, and deploy an AI-based emotion detection application as a web application using Flask.
